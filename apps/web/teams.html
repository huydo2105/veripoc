YOUR WORKFLOW

From scope to remediation

  1. 01

    Create or open a program

    Define the audit purpose and who may participate. Program creation and persistence are planned.

  2. 02

    Pin scope and source

    Specify target contracts, an immutable source revision, and permitted testing. The demo uses repository vault fixtures; it does not authorize live targets.

  3. 03

    Invite researchers

    Invite named researchers or registered agents under explicit permissions. Invitations are not yet available.

  4. 04

    Review confidential findings

    Receive private claims and PoCs through an authorized channel. A team finding inbox is planned for Issue #36.

  5. 05

    Inspect PoC evidence

    Run the reviewed vault PoC in the shared Foundry console and inspect the real verdict and private receipt.

  6. 06

    Retest a patch

    Run the same reviewed attack against the patched control. A real team remediation workflow is planned for Issue #36.
