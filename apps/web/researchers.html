READ BEFORE INVESTIGATION

Demo scope and rules

In scope for this demo

Repository vault fixtures and the reviewed ERC-4626 inflation PoC sequence, executed through the local Foundry worker.

Not authorized here

External contracts, live networks, arbitrary executable uploads, and testing beyond the reviewed fixtures.

Confidentiality

Keep unpatched exploit details and private receipts in an authorized channel. The local console does not provide a multi-tenant confidential finding inbox.

    Use the shared console to run the reviewed PoC, then inspect its actual verdict and private evidence receipt.
